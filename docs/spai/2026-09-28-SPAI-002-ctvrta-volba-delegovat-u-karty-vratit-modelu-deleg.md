# SPAI-002: Čtvrtá volba "delegovat" u karty: vrátit modelu delegation brief a nechat ho volat nástroj subagent (ExtensionAPI nemá API pro spawn, takže plugin brief pouze sestaví a deleguje model) - brief potřebuje nová pole scope a constraints, proof jako "Done when", stav delegated/čeká na důkaz, protože subagent quick_win_done volat nemůže (recursion guard) - TAIL_LINES v layout.ts je natvrdo 6, musí se nejdřív odvodit z CHOICES.length, jinak se ořízne nový řádek - delegovat se vyplatí jen pro samostatný přírůstek běžící paralelně, ne pro 20minutovou práci ?
